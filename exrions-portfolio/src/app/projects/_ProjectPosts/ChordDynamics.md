Chord Dynamics - My first satisfying UI prototype, and very first logo design

Chord Dynamics is a project made for my portfolio. It's main focus was for me to design modern UI for an interest of mine, audio. Featuring an web interface and a music streaming app. It also served as an avenue for me to learn more about logo design sincce I had no prior experience.
# Introduction
As part of my portfolio update towards entering DigiPen Singapore's User Experience and Game Design degree, I created this project as one of the stakes in UI design and logo design. 
There was not much to this project other than simply spearheading my self-improvement of my skillset towards modern UI trends and venturing into logo design.
# Process
The overall theme of the app was made with atmosphere in mind, to create a place that feels like the user's comfort music through colours and blur. 
![Chord Dynamics Logo](/posts/ChordDynamics_Logo.png)
The logo was made to use negative space to illustrate the 'C' in Chord and positive space for the 'D' in Dynamics. But this didn't turn out as well as I thought. But I thought it was a good attempt for my first logo. Courtesy of Inkscape!
